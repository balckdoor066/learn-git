AI Lab — Software Factory

A sandboxed environment where AI builds, tests, and delivers — you just paste a URL.

Overview

AI Lab is a self-hosted build system that takes a GitHub repository URL, clones it into a Docker sandbox, detects the language and framework, installs dependencies, runs tests, and generates an AI-powered summary. The entire pipeline runs automatically on your OpenClaw home server.

Key Features

Auto-detect language • Docker sandboxed builds • Real-time progress via WebSocket • AI test summaries • Bilingual dashboard (EN/TH) • REST API • Build history • Toast notifications

Quick Start

Prerequisites

  • Node.js v18+ installed on the server
  • npm package manager
  • Docker (for sandboxed builds)

Installation

# Clone or copy files to server
mkdir -p ~/ailab
scp index.html style.css script.js server.js bear1234@192.168.2.38:~/ailab/

# Install dependencies
cd ~/ailab
npm init -y
npm install ws

# Start the server
PORT=8081 node server.js

Success

AI Lab is now running at http://192.168.2.38:8081/

Submitting a Build

  1. Go to the Home page
  2. Paste a GitHub repository URL into the input field (e.g. https://github.com/user/project)
  3. Click Build
  4. The build appears in Active Builds with a progress bar
  5. Real-time updates are sent via WebSocket

Note

If the server is not connected, the build runs in demo/simulation mode with sample progress steps.

Build Detail

Click any build card to open the detail modal. It shows:

  • Status, Language, Duration, Tests — Summary stats at the top
  • AI Summary — AI-generated analysis of the build result
  • Build Steps — Clone → Analyze → Dependencies → Build → Test → QC → Package
  • Build Log — Syntax-highlighted terminal output

Connection Flow

  1. Enter the Host URL
  2. Click Save & Connect
  3. Dashboard pings GET /api to verify the server
  4. If REST succeeds, opens a WebSocket connection to /ws
  5. Status dot turns green on success

WebSocket Events

The WebSocket connection enables real-time updates from the server.

Event TypeDirectionDescription
connectedServer → ClientSent on connection open
build:startedServer → ClientNew build submitted
build:progressServer → ClientBuild progress update (0–100)
build:completedServer → ClientBuild finished with results
pingClient → ServerHeartbeat check
pongServer → ClientHeartbeat response
webhookServer → ClientExternal webhook forwarded

Example Message

// Server → Client: build progress
{
  "type": "build:progress",
  "job_id": "20260412082500-a1b2c3",
  "progress": 65
}

// Server → Client: build completed
{
  "type": "build:completed",
  "build": {
    "job_id": "20260412082500-a1b2c3",
    "repo_url": "https://github.com/user/project",
    "status": "PASSED",
    "duration_seconds": 14,
    "tests": { "total": 24, "passed": 24, "failed": 0 },
    "ai_summary": "Build completed successfully. All tests passed."
  }
}

Auto Reconnect

ConnChannel automatically handles connection drops:

  • Periodic ping — REST health check every 30 seconds
  • WebSocket reconnect — Automatic reconnect on close/error
  • Status indicator — Sidebar dot and action bar dot reflect connection state
  • Activity log — All connection events logged on the Connection page

API Reference

The AI Lab server exposes a REST API on the same port as the dashboard.

Base URL

http://192.168.2.38:8081/api

Health Check

GET /api

Returns server status and build count.

// Response
{
  "status": "ok",
  "server": "AI Lab",
  "version": "1.0",
  "uptime": 3600.5,
  "builds": 12
}

Builds

List All Builds

GET /api/builds

Returns an array of all builds, newest first.

Get Build by ID

GET /api/builds/:id

Returns a single build object by job ID.

Submit a Build

POST /api/builds

// Request body
{
  "repo_url": "https://github.com/user/project"
}

// Response (201 Created)
{
  "job_id": "20260412082500-a1b2c3",
  "repo_url": "https://github.com/user/project",
  "status": "RUNNING",
  "language": "auto",
  "started_at": "2026-04-12T08:25:00.000Z",
  "duration_seconds": 0,
  "tests": null,
  "ai_summary": null,
  "progress": 0
}

Webhook

POST /api/webhook

Receives external webhooks (e.g. from GitHub) and broadcasts them to all WebSocket clients.

// Any JSON body is accepted
// Response
{ "received": true }

Deploy to Server

File Transfer

# From your local machine
scp index.html style.css script.js server.js docs-en.html docs-th.html \
    bear1234@192.168.2.38:~/ailab/

Start Server

cd ~/ailab
npm install ws
PORT=8081 node server.js

Nginx Reverse Proxy (Optional)

To serve AI Lab under the OpenClaw domain:

# /etc/nginx/sites-available/ailab
server {
    listen 80;
    server_name ailab.local;

    location / {
        proxy_pass http://127.0.0.1:8081;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}

Systemd Service

To keep AI Lab running after reboot:

# /etc/systemd/system/ailab.service
[Unit]
Description=AI Lab Server
After=network.target

[Service]
Type=simple
User=bear1234
WorkingDirectory=/home/bear1234/ailab
ExecStart=/usr/bin/node server.js
Environment=PORT=8081
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
# Enable and start
sudo systemctl daemon-reload
sudo systemctl enable ailab
sudo systemctl start ailab

# Check status
sudo systemctl status ailab

Language (EN/TH)

The dashboard supports English and Thai. Switch languages using the EN/TH buttons in the sidebar.

  • Language preference is saved in localStorage under key ailab-lang
  • All UI elements use data-i18n attributes for translation
  • The t(key) function resolves translation keys
  • Falls back to English if a Thai translation is missing
