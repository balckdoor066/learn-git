# Hermes Pixel Office

Interactive pixel-art command center for the 7-agent Hermes AI team.

## Phase 1

- Static pixel art office map with 7 clickable workstations
- Agent info/chat drawer with model, provider, status, XP, quick actions
- Meeting room group-chat mock flow with selectable invitees
- Status bar, mini kanban preview, and agent training leaderboard
- Runs with Vite on port 3002

## Run

~~~bash
npm install
npm run dev
~~~

Open http://localhost:3002.
